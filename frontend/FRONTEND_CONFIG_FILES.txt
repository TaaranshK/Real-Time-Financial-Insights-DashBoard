SETUP COMMANDS:
===============

# Create Vite project
npm create vite@latest financial-dashboard -- --template react

# Install Tailwind
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# Install other dependencies
npm install axios react-router-dom react-icons chart.js react-chartjs-2 framer-motion

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview


ENVIRONMENT VARIABLES REFERENCE:
================================

Development:
VITE_API_URL=http://localhost:5000/api

Staging:
VITE_API_URL=https://api-staging.yourdomain.com/api

Production:
VITE_API_URL=https://api.yourdomain.com/api


ACCESSING ENVIRONMENT VARIABLES IN CODE:
========================================

// In any component or file
const API_URL = import.meta.env.VITE_API_URL;
const APP_NAME = import.meta.env.VITE_APP_NAME;
const APP_VERSION = import.meta.env.VITE_APP_VERSION;

// Conditional features
if (import.meta.env.VITE_ENABLE_DEBUG) {
  console.log('Debug mode enabled');
}


DEPLOYMENT CONFIGURATION:
=========================

For Vercel:
- Create vercel.json (optional)
- Connect GitHub repo
- Set environment variables in Vercel dashboard
- Deploy button: Deploy

For Netlify:
- Connect GitHub repo
- Build command: npm run build
- Publish directory: dist
- Set environment variables in Netlify dashboard
- Auto-deploy on push

For AWS S3 + CloudFront:
- Build: npm run build
- Upload dist/ to S3 bucket
- Create CloudFront distribution
- Point domain to CloudFront
