STEP 1: Create React Project
============================

Using Vite (recommended - faster):
```bash
npm create vite@latest financial-dashboard -- --template react
cd financial-dashboard
npm install
```

Or using Create React App:
```bash
npx create-react-app financial-dashboard
cd financial-dashboard
```


STEP 2: Install Dependencies
=============================

```bash
# Tailwind CSS
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# HTTP client
npm install axios

# Routing
npm install react-router-dom

# Icons
npm install react-icons

# Charts
npm install chart.js react-chartjs-2

# Animations (optional)
npm install framer-motion

# Local storage
npm install js-cookie
```


STEP 3: Configure Tailwind CSS
===============================

Update tailwind.config.js:
```javascript
module.exports = {
  content: [
    "./index.html",
    "./src/**/*.{js,jsx}",
  ],
  theme: {
    extend: {
      colors: {
        primary: '#3B82F6',
        secondary: '#1F2937',
        success: '#10B981',
        danger: '#EF4444',
        warning: '#F59E0B',
      }
    },
  },
  plugins: [],
}
```

Update src/index.css:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
}
```

Create .env file:

PROJECT STRUCTURE EXPLAINED:
===========================

components/
- Reusable UI components
- Used across multiple pages
- Examples: Button, Input, Card, Navbar

pages/
- Full page components
- One component per page/route
- Examples: Dashboard, Portfolio, Settings

services/
- API communication
- Axios instance setup
- All API calls centralized

hooks/
- Custom React hooks
- Reusable logic
- Examples: useAuth, useFetch

context/
- Global state management
- Share data across components
- Examples: User data, Auth status

utils/
- Helper functions
- Constants
- Examples: formatCurrency, apiUrl

CODING CONVENTIONS:
===================

Components:
- Functional components only
- Use hooks for state
- Props destructuring
- JSDoc comments for clarity

Naming:
- PascalCase for components
- camelCase for functions/variables
- kebab-case for file names (optional)

Styling:
- Tailwind classes only
- No inline styles
- Responsive design first

Structure:
- Import statements
- Component function
- JSX return
- Export default

Beginner Pattern:
```javascript
// 1. Imports
import React, { useState } from 'react';
import { useNavigate } from 'react-router-dom';
import Button from '../components/Button';

// 2. Component
export default function Login() {
  // 3. State
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const navigate = useNavigate();

  // 4. Functions
  const handleLogin = async () => {
    // Login logic
  };

  // 5. JSX Return
  return (
    <div className="min-h-screen bg-gray-100 flex items-center">
      <form onSubmit={handleLogin}>
        {/* Form JSX */}
      </form>
    </div>
  );
}
```


RESPONSIVE DESIGN:
==================

Mobile First Approach:
- Design for mobile first
- Then enhance for larger screens
- Use Tailwind breakpoints

Breakpoints:
- sm: 640px
- md: 768px
- lg: 1024px
- xl: 1280px
- 2xl: 1536px

Example:
```jsx
<div className="
  w-full           // 100% width on all screens
  md:w-1/2         // 50% on medium and up
  lg:w-1/3         // 33% on large and up
  px-4 md:px-8    // Padding adjusts
">
  Content
</div>
```

DEBUGGING:
==========

React DevTools:
- Chrome extension
- See component tree
- Inspect state & props

Network Tab:
- Chrome DevTools → Network
- See API requests
- Check response data

Console:
- Chrome DevTools → Console
- See errors
- console.log() for debugging

Common Issues:
- CORS errors → Check backend CORS config
- 404 API errors → Check API_URL in .env
- Token errors → Check localStorage/cookies
- CSS not loading → Check Tailwind config
